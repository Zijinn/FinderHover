# Mac工具箱

原生 macOS 菜单栏工具箱，目前包含两个工具：**任意应用的悬停切窗**和**临时文件口袋**。所有功能都在同一个菜单栏图标的菜单里扩展，不额外开窗。

为兼容现有辅助功能授权，应用内部 Bundle ID `com.zijin.FinderHoverPrototype` 和可执行文件名 `FinderHover` 保持不变；系统显示名称和发布包名称为“Mac工具箱”。

## 工具一：悬停切窗（不再限于访达）

把鼠标停在 Dock 的应用图标上，会在图标旁弹出该应用的窗口列表，点击即切换到对应窗口。

- 适用于任意在 Dock 中且正在运行的应用：访达、Word、Excel、PowerPoint、预览、Safari、Chrome、Edge、终端、Xcode 默认开启；Code、备忘录、邮件、飞书、Typora 等已安装但未默认开启，可在菜单里勾选。
- 菜单 →“窗口切换（悬停 Dock 图标）”→“启用哪些应用…”可按应用勾选开关；每个应用的子菜单还能单独设置是否列出最小化窗口、最多列出多少个窗口，已手动添加的应用可以移除。
- “添加其他应用…”可以选择 `/Applications` 里的任意 `.app`。
- 菜单 →“面板外观…”用滑块实时调整行高、标题字号、宽度上限、最大高度占比、距 Dock 间隙、圆角和玻璃底色；“宽度自适应标题”可关闭自适应，“恢复默认外观”一键还原。改动即时生效并写入偏好。
- 自适应无需配置：Dock 在底部/左/右自动识别（读取系统 `com.apple.dock` 方向），面板尺寸受屏幕可视区域约束，多显示器（含负坐标副屏）不会跳到主屏，标题重复时自动加序号，空标题显示“未命名窗口”，对话框、浮动面板、装饰窗口不会出现在列表里。
- 菜单 →“显示当前应用窗口”可不依赖悬停直接列出前台应用的窗口；“界面预览（示例数据）”在未授权时也能查看排版效果。
- 面板快捷键可在菜单里录入（与口袋快捷键相互独立）。

真实悬停、读取和切换窗口需要在**系统设置 → 隐私与安全性 → 辅助功能**中授权“Mac工具箱”。未授权时菜单、外观、预览和口袋都可用，只有真实窗口切换不可用。

## 工具二：临时口袋

- 默认按 `⌥Space` 在任何应用中打开临时口袋；晃动菜单栏图标两次，或从菜单打开。
- 将文件或图片拖到菜单栏图标或口袋面板中收纳。普通文件保留原位置；剪贴板截图可从口袋中的“收纳剪贴板图片”按钮导入为 PNG。
- 从口袋拖出一个或多个条目时默认复制，条目仍留在口袋中。口袋在应用退出时清空。
- 菜单 →“临时口袋”可开关该工具、查看数量、清空，以及录入/恢复默认快捷键。

口袋不读取微信私有缓存，不需要屏幕录制权限。

## 发布

当前版本 `0.3.0`。打包脚本生成 `Mac工具箱-0.3.0.dmg`，内部应用显示名称为“Mac工具箱”。

## 构建

需要 macOS 与 Xcode 命令行工具：

```bash
./build.sh
./test.sh
```

`./test.sh` 会重新构建应用并跑离线验证：几何与状态机 23 项、口袋 28 项、快捷键 23 项、通用模型与偏好 70 项，再加浅色/深色渲染预览、菜单结构自检和诊断报告。真机悬停/切换只在已授权时有效，否则诊断输出 `accessibilityTrusted=false` 并标记 BLOCKED。

`./test.sh --integration` 会额外尝试真实 Dock 悬停与窗口切换（需要辅助功能授权）。

本地生成 DMG：

```bash
./package-dmg.sh
```

GitHub Actions 对匹配 `v*.*.*` 的 tag 自动构建发布包。
